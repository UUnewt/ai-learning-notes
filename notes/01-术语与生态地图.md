# 01 · 术语与生态地图

> 一句话总结：**Model 是脑子，Harness 是身体，Agent 是会干活的人，产品是包装好卖给你的那个东西。**

## 1. 四个概念的定义

### Model（模型）

一堆权重文件。输入 token，输出 token，**除此之外什么都不做**。它不会读你的文件，不能上网，也记不住上一次对话。

### LLM（大语言模型）

Model 的一个子类，专精文本（现在也逐步支持图像、音频）。所以「LLM」和「Model」不是并列关系，是**包含关系**：

```
Model
└── LLM（大语言模型）
    ├── GPT 系列
    ├── Claude 系列
    └── GLM / Kimi / DeepSeek 系列
```

### Harness（运行框架 / 脚手架）

把模型接到真实世界的那个「外壳」。它负责：

- **工具调用**：让模型能执行命令、查网页、调 API
- **文件读写**：读你的代码、改你的文档
- **终端执行**：跑测试、装依赖
- **上下文管理**：决定哪些内容塞进模型的上下文窗口
- **循环与重试**：干错了自己看报错再来一遍
- **沙箱**：限制它能碰什么，防止闯祸

DeepSeek 官方文档里那句 slogan 讲得最清楚：

> Agent = Model + Harness
>
> 模型是 Agent 的灵魂，Harness 给予 Agent 理解环境、使用工具、并在真实场景中持续工作的能力。

### Agent（智能体）

```
Agent = Model + Harness + 工具 + 记忆 + 循环
```

判断一个东西是不是 Agent，看它**能不能自己连续做多步**：自己决定下一步、自己调用工具、自己看结果再调整。只能一问一答的是聊天机器人，不是 Agent。

### 产品（App）

```
产品 = Agent + UI + 账号体系 + 计费 + 协作功能
```

## 2. 五层关系图

```
┌─────────────────────────────────────────────┐
│  产品 / 应用    ChatGPT  WorkBuddy  Qoder ... │  ← 你付钱、点按钮的那一层
├─────────────────────────────────────────────┤
│  Agent          Claude Code  各类 CLI Agent  │  ← 会自己连做多步
├─────────────────────────────────────────────┤
│  Harness        DeepSeek Harness 等运行时     │  ← 接工具、读文件、跑循环
├─────────────────────────────────────────────┤
│  Model / LLM    GPT-6.1 sol  Sonnet 5.5 ...  │  ← 只有权重，只会吐 token
└─────────────────────────────────────────────┘
```

**关键理解**：同一个模型，换个 harness 就是完全不同的产品能力；同一个 harness，换个模型就是另一个智商水平。所以「壳」和「脑子」可以分开挑——这也是 cc-switch 这类工具存在的原因（给 Claude Code 换供应商/换模型）。

## 3. 名单分类

| 名字 | 归类 | 依据 |
|---|---|---|
| GPT-6.1 sol | Model | 模型名，`sol` 是同级变体后缀 |
| Sonnet 5.5 | Model | Anthropic Claude 家族的中档模型 |
| glm 5.3 | Model | 智谱 GLM 系列 |
| Kimi K3.1pro | Model | 月之暗面 Kimi 系列，`pro` 是高配版 |
| DeepSeek-V4.1-Flash-1017 | Model | `Flash` 轻量快版，`1017` 是版本日期快照 |
| DeepSeek Harness | Harness | 官方开源 Agent 运行时（`deepseek-ai/deepseek-harness`，MIT，Cordis 插件内核，npm 包 `@deepseek-ai/dsh`） |
| Claude Code | Agent 产品 | 跑在终端里的编码智能体，自带 harness |
| Qoder | 产品 | 阿里的 AI IDE + CLI（前身通义灵码） |
| ZCode | 产品 | 智谱的桌面 Agent 客户端，主打长任务 |
| WorkBuddy | 产品 | 桌面工作台，内置 harness，编程 + 办公 |
| ChatGPT | 产品 | OpenAI 的消费端应用，背后是 GPT 系列模型 |

### 易混点

- **ChatGPT 不是模型**，GPT 才是模型；ChatGPT 是产品。
- **DeepSeek Harness 不是模型**，它是运行时；它默认接 DeepSeek API，但也能挂别的 OpenAI 兼容端点。
- **Claude Code 不是模型**，它是 Agent；它用的模型是 Sonnet / Opus 系列。
