# 02 · Markdown 语法速查

> 原则：只学「写笔记和 README 真的会用到的」，边写边查，不背语法表。

## 1. 标题

```markdown
# 一级标题（每篇只用一个）
## 二级标题
### 三级标题
```

## 2. 强调

| 写法 | 效果 |
|---|---|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `` `行内代码` `` | `行内代码` |

## 3. 列表

无序列表用 `-`，有序列表用 `1.`，嵌套缩进两个空格：

- 第一层
  - 第二层
    - 第三层
- 回到第一层

任务清单（GitHub 上会自动变成勾选框）：

- [x] 已完成的
- [ ] 未完成的

## 4. 表格

```markdown
| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| a | b | c |
```

| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| 内容 | 内容 | 内容 |

## 5. 代码块

三个反引号 + 语言名，VS Code 里会被正确高亮：

````markdown
```c
#include <stdio.h>
int main(void) {
    printf("Hello\n");
    return 0;
}
```
````

```c
#include <stdio.h>
int main(void) {
    printf("Hello\n");
    return 0;
}
```

## 6. 引用

```markdown
> 引用内容
>> 嵌套引用
```

> 引用内容
>> 嵌套引用

## 7. 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](images/demo.png)
<https://自动变成链接的网址>
```

## 8. 分隔线与换行

- 分隔线：单独一行写 `---`
- 换行：行尾加两个空格，或空一行分段（推荐空一行，更清晰）

## 9. 高级但实用

### 折叠块（GitHub 支持）

```markdown
<details>
<summary>点开看详情</summary>

这里是被折叠的内容。

</details>
```

<details>
<summary>点开看详情</summary>

这里是被折叠的内容。

</details>

### 脚注

正文里写 `[^1]`，文末定义 `[^1]: 说明`。[^1]

[^1]: 这就是脚注的效果。

### 锚点跳转

```markdown
[跳到第 5 节](#5-代码块)
```

[跳到第 5 节](#5-代码块)

## 10. 我的三条实践规则

1. **每篇开头一句话总结**：读者（包括三个月后的我）三秒钟知道这篇在讲什么。
2. **表格优于长列表**：三类以上的并列信息，用表格。
3. **代码块一定标语言**：` ```c `、` ```bash `，否则不高亮也不方便复制。

## VS Code 里怎么用

| 操作 | 快捷键 |
|---|---|
| 打开预览 | `Ctrl + K` 然后 `V`（侧边预览） |
| 打开预览（新标签） | `Ctrl + Shift + V` |
| 粗体 | `Ctrl + B` |
| 插入链接 | `Ctrl + K` 然后松开再按 `Ctrl + V`（需选中文字） |
| 格式化表格 | 光标放表格里，`Alt + Shift + F`（Markdown All in One） |

> markdownlint 会在右下角标黄线提示格式问题，鼠标悬停能看原因。不用全改，`MD013`（行长度）这类规则可以关掉。
